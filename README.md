# West Coast Roadtrip 2027

Dette er en første, fungerende nettsideprototype for USA-roadtripen.

## Innhold
- Responsiv nettside på norsk
- Oversikt og inspirasjonsbilder
- Interaktivt kart med foreløpig rute
- Dag-for-dag-utkast for 20. juni–5. juli 2027
- Overnattingsområder og bookinglenker
- Fire prioriterte naturområder
- Redigerbart budsjett per person og for 11 personer
- Pakkeliste og huskeliste (avkryssing lagres lokalt i nettleseren)

## Viktig
Reiseruten og budsjettet er foreløpige. Kontroller kjøretider, veistatus, åpningstider, inngangsregler og priser før bestilling. Bildene lastes fra Unsplash, kartet fra OpenStreetMap og Leaflet lastes fra CDN, så nettsiden trenger internettforbindelse.

## Publiser gratis med GitHub Pages
1. Opprett/logg inn på https://github.com
2. Velg **New repository**. Kall det f.eks. `usa-roadtrip-2027`.
3. Velg **Public** og opprett repoet.
4. Pakk ut ZIP-filen på PC-en.
5. Last opp `index.html` og `README.md` til repoets rotmappe (Add file → Upload files → Commit changes).
6. Gå til Settings → Pages.
7. Under Build and deployment velger du **Deploy from a branch**.
8. Velg branch `main` og folder `/ (root)`, trykk Save.
9. Etter litt får du en nettadresse omtrent slik:
   `https://DITT-GITHUB-NAVN.github.io/usa-roadtrip-2027/`

Du trenger ikke endre koden for å publisere. Når du senere vil oppdatere innhold, kan jeg hjelpe deg med å endre filen og laste opp den nye versjonen.
